# Hi, I'm Chimthulu

I build **Discord bots, audio tools and browser games**. TypeScript, Python and Three.js, with a lot of AI-assisted engineering
and a habit of testing things for real before calling them done.

**Open to freelance work:** Discord bots, small automation tools, browser apps. Fiverr and Upwork profiles are on the way.
